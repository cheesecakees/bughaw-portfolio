HOW TO USE (Vite React project)
1. Delete everything inside your project's src/ folder (App.css, index.css, assets, old components...).
2. Copy the src/ folder from this zip into your project (replace). Also replace index.html in the project root.
3. In the terminal:  npm install   then   npm run dev
4. Edit your details in src/data/portfolio.js only.
Photos: put images in the public/ folder, then write '/filename.jpg' in portfolio.js (photo / image fields).
No extra packages needed (only react + react-dom).
